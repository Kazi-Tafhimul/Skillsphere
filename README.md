# SkillSphere 🚀
**A Modern Full-Stack Learning Management Platform**

## 🌐 Live Link
**View the Live Site:** [https://skillsphere-woad.vercel.app/](https://skillsphere-woad.vercel.app/)

## 🎯 Purpose
SkillSphere is a high-performance educational platform built to bridge the gap between students and instructors. By leveraging modern web technologies, it provides a seamless interface for course discovery, secure user authentication, and personalized profile management.

## ✨ Key Features
* **Advanced Authentication:** Integrated with **Better Auth**, supporting secure Email/Password registration and **Google OAuth** social login with automatic account linking.
* **Instant Search & Filtering:** Features a high-speed search engine that allows users to filter the course library by **title** and **category** in real-time.
* **Fluid User Experience:** Utilizes **Framer Motion** for smooth animations and **React Toastify** for instant user feedback.
* **Dynamic Course Catalog:** Includes detailed course information, instructor showcases, and a responsive grid layout.
* **User Profile System:** Logged-in users can view their persistent session data and manage their identity across the platform.

## 📦 Tech Stack & Packages

### Frontend
* **Next.js 16 (App Router):** For optimized server-side rendering and routing.
* **React 19:** Utilizing the latest concurrent rendering features.
* **Tailwind CSS 4.0:** High-performance, utility-first styling.
* **DaisyUI 5.0:** For clean, accessible, and themeable UI components.
* **Framer Motion:** For interactive UI animations.
* **React Icons:** For a comprehensive set of scalable icons.
* **React Toastify:** For elegant notification handling.

### Backend & Authentication
* **MongoDB:** Direct database interaction via the native `mongodb` driver.
* **Better Auth:** A modern auth framework using the **MongoDB Adapter** for secure session and user management.
